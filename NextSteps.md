### Step 5: Convert the EMA chunks to the project's format (the main job)
The project loads every `knowledge-base/corpus/*.json` file. The converter is now available at `Data_extraction/scripts/convert_eu_to_corpus.py`. It includes adopted, non-superseded `monograph` and `report` documents and preserves draft wording in published titles.

What it must do, based on the project's code and database:

| Your `eu_chunks.jsonl` | Project `corpus/*.json` |
|---|---|
| one line per chunk | `documents[]` with `chunks[]` inside |
| `doc_name` | document `title` (**≤ 500 chars**, **must be unique** per PDF) |
| (fixed) | `authority`: `European Medicines Agency (HMPC)` |
| `doc_kind` | `document_type` (e.g. `monograph`, `assessment report`) and `category`: `herbal` |
| `source_url` | `source_url` |
| `section_number` + `section_title` + page | chunk `section_identifier` (**≤ 255 chars**), e.g. `Section 4.2 Posology (p. 3)` |
| `text` | chunk `verbatim_text` |
| herb name + `doc_kind` | chunk `retrieval_context` |
| (fixed) | `verification_status`: `pending_human_check` |

**Important: use `"jurisdiction": "international"`.** The database only accepts `india` or `international` (`CHECK` constraint in `database/init.sql`). If you write `eu`, seeding will fail. Do not change the database for this.

Output file: `Ayushakti/knowledge-base/corpus/eu_herbal.json`.
